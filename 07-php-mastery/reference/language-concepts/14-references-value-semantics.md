# 值语义与引用（&）

> **模块**: `07-php-mastery` | **类型**: 字典条目（无难度门槛，支持任意跳入查阅）

## 📌 定义

PHP 默认是**值语义**：赋值、传参、返回都复制变量（数组等结构写时复制优化，行为上等同复制）。`&` 显式建立引用——两个变量名指向同一存储。对象是最大例外：变量保存的是**对象标识符（handle），按值复制**，所以"对象像引用一样传播"是 handle 被复制的表象，而非真引用。

## 一、对象传参的真相：标识符按值传

```php
class Box { public int $v = 1; }

function tweak(Box $b): void
{
    $b->v = 99;       // 通过复制来的 handle 改到同一对象 → 生效
    $b = new Box();   // 重新绑定的是局部副本 → 不影响调用方
    $b->v = 55;
}

$box = new Box();
tweak($box);
var_dump($box->v);    // int(99)，不是 55
```

复制来的 handle 与原 handle 指向同一对象：`$a2 = $a1;` 后 `$a1 === $a2` 为 true，`spl_object_id` 相同（实测）。要让"重新绑定"也影响调用方，才需要真正的引用。

## 二、& 的四种形态

```php
// 1. 引用赋值：$q 与 $p 是同一存储的两个名字
$p = 1;
$q = &$p;
$q = 2;            // $p 也是 2
unset($q);         // 只摘除 $q 这个名字，$p 不受影响（实测 $p 仍为 2）

// 2. 引用传参：函数内可改外部变量
function bump(int &$n): void { $n++; }

// 3. foreach 引用：循环内修改元素
foreach ($arr as &$item) { $item *= 2; }

// 4. 函数返回引用：& 必须同时出现在声明与使用两侧
$holder = ['k' => 'old'];
function &slot(array &$h): string { return $h['k']; }
$r = &slot($holder);
$r = 'new';        // $holder['k'] === 'new'（实测）
```

`global $x;` 本质是建立引用：函数内修改会反映到全局（实测输出 "changed"），但 `unset($x)` 只摘掉函数内的名字。

## 💡 示例：值复制 vs 引用

```php
$a = [1, 2];
$b = $a;           // 值语义：行为上复制
$b[0] = 9;
var_dump($a[0]);   // int(1)，$a 不受影响

$c = &$a;          // 引用：同一存储
$c[0] = 9;
var_dump($a[0]);   // int(9)
```

对象需要"真正的复制"时用 `clone`（浅复制，可用 8.5 的 `clone($obj, ['prop' => $v])` 指定属性覆盖，见魔术方法条目）。

## ⚠️ 常见陷阱

- ❌ **foreach 引用循环结束后继续使用 `$item`**：残留引用会让后续同名循环污染最后一个元素（实测：`foreach ($arr as &$x) {}` 结束后执行 `$x = 100;`，`$arr[2]` 变成 `&int(100)`）。
- ✅ 引用式 foreach 结束后立刻 `unset($item)`。
- ❌ **以为对象赋值/传参是"完整引用"**：只有成员修改共享，**重新赋值**（`$param = new ...`）不影响调用方。
- ✅ 需要重绑定效果时显式 `function f(&$obj)`。
- ❌ **认为 `unset()` 一个引用会释放原变量**：`unset` 只解除名字与存储的绑定，其余引用继续存活。
- ✅ 用引用计数的心智模型：存储在最后一个引用 `unset` 后才释放。
- ❌ **滥用 `&` 传参"提高性能"**：PHP 数组写时复制，传值并不立即复制；额外引用反而抑制 COW 并妨碍优化。
- ✅ 默认按值传递；确需原地修改时才用 `&`。
- ❌ **返回引用而不写全两个 `&`**：只写赋值侧 `$r = &f()` 或只写声明侧都退化为普通复制。
- ✅ `function &f(): type` 声明 + `$r = &f();` 调用，两侧配对。
