# os - 进程环境与文件系统

> **模块**: `01-go-backend` | **类型**: 字典条目（无难度门槛，支持任意跳入查阅）

## 📌 定义

os 包是 Go 与**操作系统打交道的大门**：文件与目录操作、环境变量、进程信号、标准流与进程退出。心智模型——`*os.File` 实现了 `io.Reader/Writer/Closer`，于是文件天然接入 io 生态；进程级操作（Exit/Signal）与语言层 defer 的交互必须牢记。

## 📖 语法 / 签名

```go
// 文件读取：小文件一把梭 vs 流式
data, err := os.ReadFile("config.json")        // 全量读入内存（小文件）
f, err := os.Open("big.log")                   // 只读打开（文件不存在报 *PathError）
defer f.Close()
br := bufio.NewScanner(f)                      // 大文件按行流式（见 io/bufio 条目）

// 文件写入
err := os.WriteFile("out.txt", []byte("hi"), 0o644)  // 覆盖写全量
w, err := os.Create("out.txt")                       // 创建/截断，返回 *os.File 可写
w, err := os.OpenFile("app.log", os.O_APPEND|os.O_CREATE|os.O_WRONLY, 0o644)

// 环境变量
s := os.Getenv("HOME")        // 不存在返回 ""（无法区分未设置）
val, ok := os.LookupEnv("HOME") // 双值形式才可区分
os.Setenv("K", "v"); os.Unsetenv("K")
env := os.Environ()           // []string，每条 "KEY=value"

// 进程级
os.Exit(1)                    // 立即退出，defer 不执行
os.Args                       // 命令行参数（含程序名）
os.Getpid(); os.Getwd()

// 信号
sig := make(chan os.Signal, 1)
signal.Notify(sig, os.Interrupt, syscall.SIGTERM)
```

## 💡 示例

```go
package main

import (
	"fmt"
	"os"
	"os/signal"
	"path/filepath"
	"syscall"
	"time"
)

func main() {
	// 1. ReadFile / WriteFile：小文件直读直写
	if err := os.WriteFile("/tmp/osdemo.txt", []byte("hello os"), 0o644); err != nil {
		panic(err)
	}
	data, err := os.ReadFile("/tmp/osdemo.txt")
	fmt.Println(string(data), err == nil) // hello os true

	// 2. Open + 流式读：文件即 io.Reader
	f, err := os.Open("/tmp/osdemo.txt")
	if err != nil {
		panic(err)
	}
	defer f.Close()
	buf := make([]byte, 8)
	n, _ := f.Read(buf)
	fmt.Println(string(buf[:n])) // hello os

	// 3. 环境变量：LookupEnv 区分"空值"与"未设置"
	os.Setenv("DEMO_MODE", "")
	v, ok := os.LookupEnv("DEMO_MODE")
	fmt.Println(v == "", ok) // true true（设置了但为空）
	_, ok2 := os.LookupEnv("DEFINITELY_NOT_SET_42")
	fmt.Println(ok2) // false

	// 4. 路径处理：跨平台拼路径
	fmt.Println(filepath.Join("a", "b", "c.txt")) // a/b/c.txt

	// 5. 信号处理：优雅退出的标准骨架
	sigCh := make(chan os.Signal, 1)
	signal.Notify(sigCh, os.Interrupt, syscall.SIGTERM) // Ctrl+C 与 kill
	go func() {
		time.Sleep(10 * time.Millisecond)
		sigCh <- syscall.SIGTERM // 模拟外部 kill
	}()
	got := <-sigCh
	fmt.Println("收到信号:", got) // terminated
}

// os.Exit 陷阱独立演示（defer 不执行）：
//
//	func bad() {
//	    defer fmt.Println("cleanup")   // 永远不会打印
//	    os.Exit(1)                     // 立即终止进程
//	}
```

## ⚠️ 常见陷阱

- ❌ **错误做法**：`os.Exit` 之前依赖 defer 保存状态/刷缓冲。
- ✅ **正确做法**：`os.Exit` **不执行任何 defer、不刷 bufio**；把退出编排放在 main 顶层——返回值路径先清理，最后才 Exit。
- ❌ **错误做法**：用 `os.Getenv` 返回 "" 判断"环境变量未设置"。
- ✅ **正确做法**：`LookupEnv` 双值形式；空串可能是合法配置值。
- ❌ **错误做法**：路径拼接用 `fmt.Sprintf("%s/%s", dir, name)`。
- ✅ **正确做法**：`filepath.Join`（Windows 分隔符安全）；探查存在性用 `os.Stat` + `errors.Is(err, fs.ErrNotExist)`。
- ❌ **错误做法**：os.Open 只读句柄当可写用。
- ✅ **正确做法**：读 Open、写 Create/OpenFile + 显式 flag；权限位用 `0o644` 八进制字面量。
- ❌ **错误做法**：signal.Notify 的 channel 无缓冲，信号偶发丢失。
- ✅ **正确做法**：channel 带缓冲（`make(chan os.Signal, 1)` 起步）；用 `signal.Stop` 注销；优雅关停配合 context 超时兜底。
- ❌ **错误做法**：写文件时无视 `f.Close()` 的返回值。
- ✅ **正确做法**：写路径的 Close 错误代表数据可能没落盘；重要文件检查 Close 错误（defer + 命名返回值回写）。
